Setup 1/8

Install the foundations: Node.js LTS + Git

🪟 Windows

1. Download the LTS version from nodejs.org.

2. Install Git from git-scm.com.

3. Keep the defaults, then open a new PowerShell window.

🍎 macOS

1. Download the LTS version from nodejs.org.

2. Open Terminal and run:

xcode-select --install
Career-Ops requires Node.js 18+ and recommends 22.5+. Use an LTS release.
Do not reinstall tools that already work. Node runs helper scripts; Git lets the installer retrieve the workspace.

18

Do not read only the number

A score is a signal for investigation, not pass or fail

Read carefully

  • Which requirements does the CV prove?
  • Which gaps are hard blockers?
  • Is the job real and still open?
  • Did the AI cite its sources?

Never do this

  • Add skills you have never used
  • Change titles or achievements
  • Trust unsourced compensation
  • Submit an unread PDF
Hands-on complete: the remaining commands are focused tools for specific needs.
Emphasize that degree requirements and work authorization are real hard blockers.

Guardrails

What Codex can prepare—and what you must verify

1

Your profile

Codex can reorganize your CV, but it must never invent skills, experience, or achievements.

2

Company information

Verify salary, eligibility, deadlines, and interview information using current sources.

3

Final actions

You review and decide before submitting, emailing, signing, or publishing anything.

Use your real CV locally so Career-Ops can personalize the results. Keep personal information out of public repositories and shared screenshots.
Codex prepares drafts and recommendations. The student verifies the facts, protects personal information, and makes every final decision.
